ASIC design · Purdue ECE 337 · Three-person team

AHB Neural Network Accelerator

  • SystemVerilog
  • AHB
  • Design Compiler
  • QuestaSim

A small neural-network accelerator chip design. Software writes weights and inputs over a standard on-chip bus (AHB), an 8×8 grid of multiply-accumulate units does the math, and an activation stage shapes the results.

My partI designed the compute core: the 8×8 systolic array with its 64 pipelined processing elements, weight registers and partial-sum pipelines, and the activation stage with four modes. I verified each block and then the top level, and helped debug the integration. Teammates built the AHB subordinate, controller, SRAM buffer and top level.

64 PEsprocessing elements in the 8×8 weight-stationary array. Each one multiplies, adds the partial sum from above, and passes the result on.
8 lanesof 8-bit floating-point (FP8) values in each 64-bit word, unpacked and repacked around the activation stage.
4 modesReLU, Leaky ReLU, binary and identity, selected by a 2-bit control for every lane.
128 inputsin the longest top-level test vector, plus NaN, infinity and bus-overrun error cases.

Team responsibilities

Teammates developed the AHB subordinate, controller and input state machine, SRAM data buffer, and top level. Integration debugging was shared across the team.

The main integration challenge

Coordinating register controls, reset sequencing, and data widths across the AHB interface, controller, and array required more debugging than the array alone.

The systolic array datapath

Weights remain in each processing element while activations enter eight lanes in a staggered sequence. Each element multiplies its inputs, adds the partial sum from above, and passes the result through pipeline registers. The diagrams below show a single processing element and the full array.

03

The activation block

Designed the activation stage to unpack a 64-bit word into eight 8-bit minifloat values, apply the mode selected by a 2-bit control, and repack the results before output.

Four selectable activation modes

ReLU turns negative values into zero. Binary outputs +1 or −1 by sign. Identity passes the value through. Leaky ReLU keeps positive values and scales negative ones by 0.25. Each constant is an 8-bit minifloat encoding.

Handling signed zero

The sign check also detects zero so negative zero is handled correctly. Verification covered this numeric-format edge case.

04

Synthesis, timing analysis, and layout coursework

The accelerator was simulated in QuestaSim, synthesized in Synopsys Design Compiler, and checked through timing analysis. Separate Cadence Innovus coursework used a provided USB design to study I/O placement, interconnect delay, and timing slack.

GPU Vertex Stage

  • SystemVerilog
  • Python
  • Fixed point
  • Vivado

The first stage of a small FPGA GPU: it turns each 3D triangle into 2D screen coordinates in fixed-point math. Most of my work was making it smaller without breaking it, and proving that with tests.

My partI cut the stage from 40 to 13 DSP slices, added the clipping stage, ran the top-level verification and built the FPGA test harness. A teammate wrote the first version of the shared multiplier; I finalized and re-integrated it.

761 / 761top-level checks pass across 15 testbenches, compared with a bit-accurate Python model.
40 → 13DSP slices, changing one block at a time and re-running the tests after every change.
+0.388 nssetup slack at 125 MHz after routing in Vivado: timing is met.
≤ 1.25 pxscreen position error against the Python model, unchanged by the DSP reduction.
01

The pipeline

A triangle goes in as three vertices and comes out as screen coordinates.

02

How it was verified

Every change was checked against the same reference.

A bit-accurate model

A Python model computes the exact fixed-point result, so each testbench compares bits, not approximations.

Re-run after every change

Each DSP reduction was merged one at a time with the full suite re-run, so a failure pointed at one change.

What is still open

The stage has not run on the board yet: the lab PCs do not detect it, and the harness was built at 100 MHz.
